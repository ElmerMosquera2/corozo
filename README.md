# corozo
Una plataforma web de creación de presentaciones basada en Markdown, que convierte automáticamente documentos Markdown en diapositivas navegables y exportables como HTML.

## MVP actual

- Entrada Markdown en `textarea`
- Separación de slides con `---`
- Soporte para títulos, listas, tablas e imágenes (`http/https`)
- Preview navegable (botones y flechas de teclado)
- Exportación a un `.html` autónomo (sin dependencias externas)

## Uso

1. Abre `/home/runner/work/corozo/corozo/ElmerMosquera2/corozo/index.html` en el navegador.
2. Escribe o pega Markdown.
3. Pulsa **Generar presentación**.
4. Navega slides con botones o teclado.
5. Pulsa **Descargar HTML** para exportar.
